# Content Bất Động Sản

Thư mục chuyên làm nội dung cho mảng bất động sản: tin đăng bán/cho thuê, bài mạng xã hội, kịch bản video ngắn, bài blog chuẩn SEO.

## Cấu trúc

| Thư mục / File | Dùng để |
|---|---|
| `01-y-tuong/` | Ghi lại ý tưởng, chủ đề, góc khai thác |
| `02-mau-noi-dung/` | Mẫu có sẵn cho từng loại nội dung |
| `03-du-an/` | Hồ sơ từng dự án hoặc căn cụ thể (mỗi dự án một file) |
| `04-ban-nhap/` | Bài đang viết, chưa duyệt |
| `05-da-dang/` | Bài đã đăng (lưu lại để tái sử dụng, đo hiệu quả) |
| `06-hinh-anh-video/` | Ảnh, video, thiết kế đi kèm |
| `lich-dang-bai.md` | Lịch đăng bài theo tuần/tháng |
| `tu-khoa-hashtag.md` | Từ khóa SEO và hashtag hay dùng |

## Quy trình làm một bài

1. Lấy ý tưởng từ `01-y-tuong/ngan-hang-y-tuong.md`.
2. Nếu bài nói về một dự án, tạo hồ sơ trong `03-du-an/` từ file `_mau-ho-so-du-an.md`.
3. Chép mẫu phù hợp trong `02-mau-noi-dung/` sang `04-ban-nhap/` và viết.
4. Đối chiếu với checklist cuối mỗi mẫu (thông tin pháp lý, giá, số liệu phải chính xác).
5. Đăng xong thì chuyển file sang `05-da-dang/` và ghi kết quả (lượt xem, tin nhắn, khách quan tâm).

## Quy ước đặt tên file

`YYYY-MM-DD_kenh_chu-de.md`, ví dụ `2026-11-26_facebook_can-ho-2pn-quan-7.md`.

## Lưu ý

- Không cam kết lợi nhuận hay "chắc chắn tăng giá".
- Chỉ ghi thông tin pháp lý (sổ hồng, giấy phép xây dựng...) khi đã kiểm tra.
- Ghi rõ giá đã gồm hay chưa gồm VAT và phí bảo trì.
